# @amlplugins/google-gmail

Native `@googleapis/gmail` SDK re-exported under the `@amlplugins` namespace.

> Google Gmail (gmail_v1).

## Install

```bash
npm install @amlplugins/google-gmail
```

## Use

```ts
import { /* named exports from @googleapis/gmail */ } from "@amlplugins/google-gmail";
// or
import sdk from "@amlplugins/google-gmail";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
